# FastWAM 代码理解笔记

> [!abstract] 项目简介
> FastWAM 是论文 *Fast-WAM: Do World Action Models Need Test-time Future Imagination?*（arXiv:2603.16666）的官方实现。
> 核心思想：训练时视频专家和动作专家联合学习，推理时只用动作专家，跳过视频生成，大幅提速。

## 核心思想速记

```
训练：观察帧 → [Video Expert + Action Expert（MoT 联合）] → 视频预测 + 动作预测
推理：观察帧 → [Action Expert only]                       → 动作预测（无需视频生成）
```
