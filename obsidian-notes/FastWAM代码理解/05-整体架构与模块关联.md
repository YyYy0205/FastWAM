## 1. 核心问题与解答

> [!question] 论文核心问题
> "Do World Action Models Need Test-time Future Imagination?"
> （机器人操作模型在推理时真的需要先生成未来视频吗？）

> [!success] 答案
> **不需要。**
> 通过 MoT 联合训练，动作专家从视频专家的表示中蒸馏世界知识，
> 推理时无需显式生成视频，直接从第一帧预测动作序列。

## 3. 训练 vs 推理的差异

```
训练时：
  noisy_video ──→ Video Expert ──┐
                                 ├── MoT 混合注意力 ──→ pred_video  → loss_video
  noisy_action ─→ Action Expert ─┘                  ──→ pred_action → loss_action

推理时（infer_action）：
  first_frame ──→ Video Expert ──→ prefill KV Cache（一次）
                                          │
  noisy_action ─→ Action Expert ──→ 读取缓存 K/V ──→ pred_action → action
                  （20次去噪循环）
```

## 4. 完整调用链（infer_action）

```
infer_action(prompt, input_image, action_horizon=16)
│
├── vae.encode(input_image)
│       → first_frame_latents [1, 16, 1, 14, 14]
│
├── encode_prompt(prompt)
│       → context [1, L, 4096]
│
├── video_expert.pre_dit(first_frame_latents, t=0)
│       → video_pre dict
│             tokens: [1, 196, 3072]
│             freqs:  [196, 1, rope_dim]
│             t_mod:  [1, 6, 3072]
│
├── _build_mot_attention_mask(S_v=196, T=16, per_frame=196)
│       → attention_mask [212, 212]
│
├── mot.prefill_video_cache(video_pre)
│       → kv_cache: list[30 × {k:[1,196,3072], v:[1,196,3072]}]
│
└── for step_t in [1.0, 0.95, ..., 0.05]:  # 20 步
        │
        ├── action_expert.pre_dit(latents_action, t=step_t)
        │       → action_pre dict
        │             tokens: [1, 16, 1024]
        │
        ├── mot.forward_action_with_video_cache(action_pre, kv_cache)
        │       每层：
        │         q_action          [1, 16, 3072]
        │         k_cat = [k_video_cached | k_action]  [1, 212, 3072]
        │         v_cat = [v_video_cached | v_action]  [1, 212, 3072]
        │         mixed = flash_attention(q_action, k_cat, v_cat)  [1, 16, 3072]
        │       → action_tokens_out [1, 16, 1024]
        │
        ├── action_expert.post_dit(action_tokens_out)
        │       → pred_action [1, 16, action_dim]
        │
        └── scheduler.step(pred_action, delta_t, latents_action)
                → latents_action 更新（向干净动作方向推进）

return {"action": latents_action}   # [16, action_dim]
```

## 5. 关键设计决策速查

| 设计 | 实现 | 原因 |
|------|------|------|
| ActionDiT hidden=1024（比 Video DiT 小） | `configs/model/fastwam.yaml` | 动作语义简单，不需要大容量；但 Q/K/V 维度相同以兼容 MoT |
| 动作 token 只看第一帧视频 | `_build_mot_attention_mask` | 防止"作弊"（从未来帧直接读动作），迫使内化世界知识 |
| 独立采样视频/动作时间步 | `training_loss` | 增加训练多样性，避免一个任务主导梯度 |
| ActionDiT 从 Video DiT 插值初始化 | `preprocess_action_dit_backbone.py` | 提供更好的优化起点，加快收敛 |
| 推理时视频 KV 缓存 | `prefill_video_cache` | 节省 19×30 次 Transformer 前向计算 |
| 梯度检查点（训练时） | `mot_checkpoint_mixed_attn=true` | 混合注意力序列长（~1000），节省显存 |
| VAE 和 T5 冻结 | `_apply_dit_only_train_mode` | 固定视觉/语言表示，只让 DiT 学习去噪 |

## 6. 文件与模块对应

```
src/fastwam/
├── models/wan22/
│   ├── fastwam.py          ← FastWAM 主类：build_inputs, training_loss, infer_action
│   ├── mot.py              ← MoT：forward, prefill_video_cache, forward_action_with_video_cache
│   ├── action_dit.py       ← ActionDiT：pre_dit, post_dit, from_pretrained
│   ├── wan_video_dit.py    ← Video DiT：DiTBlock, flash_attention, RoPE
│   ├── wan_video_vae.py    ← VAE：encode, decode
│   ├── wan_video_text_encoder.py  ← T5 文本编码器
│   ├── fastwam_idm.py      ← 逆动力学模型变体
│   ├── fastwam_joint.py    ← 联合训练变体
│   └── schedulers/
│       └── scheduler_continuous.py  ← 流匹配调度器
├── trainer.py              ← 训练循环：DeepSpeed ZeRO、checkpointing
├── runtime.py              ← create_fastwam：模型实例化入口
└── datasets/
    ├── robot_video_dataset.py
    └── processors/fastwam_processor.py  ← 数据→模型输入
```
